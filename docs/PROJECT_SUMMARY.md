## 一、项目概况

### 项目名称
**CameraX-AI 驱动的智能摄影助手**（AI Smart Camera Assistant）

### 参赛类别
大学生软件创新赛事 - 移动应用开发

一款基于 Android 平台的智能摄影辅助应用，聚焦"**拍前构图辅助**"核心需求，通过 AI 技术为摄影爱好者提供实时构图建议、场景识别、智能裁剪和智能调色等功能。

## 二、痛点分析

### 用户痛点
1. **构图困难**：普通用户不了解摄影构图法则
2. **调色困惑**：后期修图需要专业知识和时间
3. **实时指导需求**：拍摄时希望获得即时建议

### 现有方案局限
- **传统相机 APP**：仅提供基础拍摄功能，缺乏智能辅助
- **后期修图软件**：需要拍摄后处理，无法改善拍摄瞬间的构图
- **云端 AI 服务**：依赖网络，隐私风险高，延迟大

---

## 三、解决方案

### 核心功能

#### 1. 实时构图辅助 ⭐ 核心亮点
- **功能**：AI 实时检测人脸位置，提供构图调整建议
- **技术**：ML Kit Face Detection + 三分法算法 + OpenCV 辅助
- **优势**：拍前指导，从源头提升质量

#### 2. 场景智能识别
- **功能**：自动识别人像、风景、美食、夜景等场景
- **技术**：ML Kit Image Labeling
- **优势**：推荐最优拍摄参数

#### 3. 智能裁剪优化
- **功能**：基于物体检测的自动裁剪建议
- **技术**：ML Kit Object Detection + 智能边距算法
- **优势**：二次构图更精准，支持多主体检测

#### 4. AI 色彩增强
- **功能**：一键智能调色
- **技术**：ONNX Runtime + 自定义调色模型
- **优势**：保持自然观感，支持6个参数调节

#### 5. 双轨 AI 架构
- **特点**：本地轻量化模型 + 云端大模型协同
- **优势**：本地保证实时性，云端提供深度理解，用户自主选择

---

## 四、技术创新

### 1. 双轨 AI 推理架构
- **本地轻量化模型**：ML Kit + ONNX Runtime + OpenCV，推理延迟 < 200ms
- **云端大模型**：阿里云百炼 qwen-vl-plus 视觉语言模型，深度场景理解
- **效果**：本地保证实时性，云端提供专业级摄影建议

### 2. 多模型融合架构
- **模型组合**：场景识别 + 人脸检测 + 物体检测 + 色彩分析 + 云端深度理解
- **协同工作**：综合分析，提供最佳建议

### 3. 智能裁剪算法
- **多主体检测**：支持检测并关联多个相关主体
- **动态边距**：根据主体大小自动调整边距
- **智能放弃**：当裁剪比例过大时自动放弃裁剪，保留原图

### 4. "拍前辅助"理念
- **差异化**：区别于传统后期修图应用
- **用户价值**：减少后期时间，捕捉不可重复瞬间

## 十、竞争优势

### 差异化定位

| 维度 | 传统应用 | 本项目 |
|------|----------|--------|
| **介入时机** | 拍摄后修图 | 拍前指导 |
| **处理方式** | 云端 AI | 本地+云端双轨 |
| **隐私保护** | 需上传 | 本地优先，云端可选 |
| **网络依赖** | 强依赖 | 本地功能无需网络 |
| **延迟** | 高（1-3 秒） | 本地低（<200ms），云端按需 |
| **比例切换** | 卡顿明显 | 平滑动画过渡 |

### 核心竞争力
1. **技术壁垒**：双轨 AI 架构、多模型融合、智能裁剪算法
2. **用户体验**：实时指导、自然增强、三种主题风格
3. **灵活隐私**：本地功能无需网络，云端功能用户自主选择
4. **可扩展性**：模块化设计，易于添加新功能
